# Profile art pipeline

All panels on the profile are self-hosted SVGs generated by these scripts.
GitHub strips `<script>` and inline CSS from READMEs but renders SMIL and CSS
keyframe animation inside `<img>`-embedded SVGs, so every animation is baked
into the file.

| Output | Script | Refresh |
| --- | --- | --- |
| `portrait.svg` | `prep_photo.py` then `make_ascii_svg.py` | manual, when the photo changes |
| `info-card.svg` | `make_info_card.py` | manual, edit `ROWS` in the script |
| `contrib-heatmap.svg` | `fetch_contributions.py` then `render_heatmap_svg.py` | daily (Actions) |
| `stats.svg` | `fetch_contributions.py` then `render_stats_svg.py` | daily (Actions) |

Palette and the shared terminal-window chrome live in `theme.py`.

## Daily refresh (CI)

`.github/workflows/update-profile-art.yml` runs at 06:17 UTC, on push to
`master`, and on demand. It scrapes the public
`https://github.com/users/A1cy/contributions` HTML (no token), writes
`data/contributions.json`, re-renders the two data panels and commits them
with `[skip ci]`. Only `requests` and `beautifulsoup4` are needed there.

## Portrait (local only)

Needs `opencv-python-headless`, `numpy`, `Pillow`. The background is cut with
OpenCV GrabCut, which is enough for a plain studio backdrop (the original
method used `rembg`, a 176 MB model that took minutes here).

```bash
uv venv .venv && uv pip install -p .venv/bin/python Pillow numpy opencv-python-headless
.venv/bin/python scripts/prep_photo.py source-photo.png   # -> source-prepped.png (gray + mask)
.venv/bin/python scripts/make_ascii_svg.py                # -> portrait.svg
```

Tuning knobs (env):

- `prep_photo.py`: `HI_PCT` (default 96, tone-stretch ceiling; lower = punchier
  but blown-out skin), `LINE_WEIGHT` (how hard eyes, brows and the smile are
  pushed to black), `SIDE_SEED` (how far down the side strips count as
  backdrop; lower it if a shoulder gets cut off).
- `make_ascii_svg.py`: `COLS` (default 180, more = finer), `GAMMA` (default
  1.0), `POSITIVE=0` for the original negative mapping (suits light line art,
  not photos), `STATIC=1` for a frozen preview frame.
